    作品配置

    以 JSON 保存每个作品自己的设置。点击保存时，会顺便留下一个可恢复的版本快照。

    新版「圣诞树」会把它自己的文字、字体、颜色与粒子密度同步到这里，并使用 line1、line2、fontKey、fontSize、color、treeParticles 和 dustParticles。 在这里恢复配置后，回到作品左侧点击「读取档案馆设置」即可应用。

    素材仓库

    照片、音乐、视频或其他文件都会保存在这台设备的 IndexedDB 中，并按作品归档。

    ＋ 拖进来，或点击选择文件 图片、音频、视频、PDF、代码文件……不限格式

    配置版本

    每次保存配置、恢复旧版本之前，都会自动留下一个快照。恢复只会改变配置，不会删除素材。

      交互时间线

      作品打开、手势、许愿、设置变化和体验时长，都会通过共享脚本写进这里。

        导出与恢复

        档案馆的完整备份是一个 JSON 文件，里面包含配置、版本、交互记录和素材本身。

        完整档案馆

        所有作品的配置、版本、素材和交互记录，打包成一份可迁移的 JSON 备份。

        当前作品

        只导出当前作品的配置、素材与交互记录。

        导入 / 恢复

        读取之前导出的 JSON。可以选择与现有档案合并，或清空后覆盖恢复。

        素材会以 Base64 形式写入 JSON，文件可能比较大。建议定期导出，并放在自己信任的位置。 未来接入云端同步时，这份 JSON 结构可以直接作为迁移格式。
