# Interactive Lab · 互动创意实验室

一个由多个独立互动网页组成的个人作品集，加上一座本地创作档案馆。

## 文件地图

| 文件 | 作用 |
| --- | --- |
| `index.html` | 主站首页：品牌、作品索引、档案馆入口 |
| `archive.html` | 创作档案馆：配置、素材、版本、交互记录、JSON 备份 |
| `christmas.html` | 正式版「圣诞树」：Three.js 粒子、手势、照片与音乐 |
| `christmas-archive-bridge.js` | 圣诞树与档案馆的桥接：同步配置、镜像素材、记录手势 |
| `christmas-quiet.html` | 早期简版圣诞树，保留作备用，主站不展示 |
| `mountain.html` | 互动作品「山海之间」 |
| `star-wanderer/` | 互动作品「星际漫游 · 情绪星云镜」：粒子星云、表情/手势、情绪配色与情绪故事 |
| `life-os.html` | 互动工具「日常节律」（原来的 Life OS） |
| `lab-archive.js` | 共享脚本：让主站和作品读写 IndexedDB 档案馆 |
| `assets/covers/` | 主站作品封面：`daily.png`、`christmas.png`、`cosmos.png` |
| `vendor/three/`、`vendor/mediapipe/` | 圣诞树的本地 Three.js 与手势模型，不再依赖 CDN |
| `backup.html` | 早期「山海之间」的旧备份，可以留着，也可以删掉 |

> 不要删除 `lab-archive.js` 和 `christmas-archive-bridge.js`。档案馆和圣诞树靠它们连接。

## 怎么打开

最简单的方式：双击 `index.html` 可以看主站，但**不建议**用这种方式体验圣诞树和档案馆。

原因有三个：浏览器可能限制 `file://` 页面的 IndexedDB；圣诞树使用了 ES Module 和 CDN 上的 Three.js；摄像头也需要一个正常的页面环境。请用下面的本地服务器方式打开整个项目。

### 方法一：VS Code 插件（推荐，适合不写代码的人）

1. 用 VS Code 打开这个文件夹。
2. 在扩展里搜索并安装 **Live Server**。
3. 右键 `index.html`，选择 **Open with Live Server**。
4. 浏览器会自动打开，地址大致是 `http://127.0.0.1:5500/index.html`。

### 方法二：Python 本地服务器

在项目文件夹里打开终端，运行：

```bash
python -m http.server 8000
```

然后打开：

```text
http://localhost:8000/index.html
```

档案馆地址：

```text
http://localhost:8000/archive.html
```

## 档案馆怎么用

打开 `archive.html` 之后：

- **左侧列表**：每件作品一个入口，点一下切换。
- **概览**：作品信息、最近交互、配置摘要。
- **配置**：以 JSON 编辑作品设置。点「保存并生成版本」会保存当前配置，并自动留下一个版本快照。
- **素材**：拖入或选择图片、音乐、PDF、代码文件等，文件会存进浏览器的 IndexedDB。
- **版本**：查看历史配置，或把配置恢复回某个时间点。恢复前会自动再存一份当前配置。
- **交互记录**：作品里发生的手势、许愿、设置变化、打开次数和体验时长。
- **导出 / 恢复**：把整座档案馆导出成一个 JSON 文件，或从 JSON 导入/恢复。素材会被转成 Base64 一起打包。

「星际漫游」已经作为可打开的正式作品接入档案馆。以前打开过档案馆的浏览器，在下次刷新 `archive.html` 时会自动把它从「制作中」迁移为上线状态。

### 圣诞树与档案馆的联动

正式版圣诞树的设置面板右上角多了两个按钮：

- **保存到档案馆**：把当前的文字、字体、颜色、装饰密度和星尘密度写进档案馆，并生成一个版本快照。
- **读取档案馆设置**：把档案馆里最近保存（或恢复）的配置读回作品。

在作品里改文字、字体、颜色或粒子密度时，也会自动同步到档案馆（约 1 秒防抖）。

配置字段：

```json
{
  "line1": "Merry",
  "line2": "Christmas",
  "fontKey": "style1",
  "fontSize": 100,
  "color": "#fceea7",
  "treeParticles": 1500,
  "dustParticles": 2500
}
```

圣诞树里上传的**照片和音乐**会同时镜像一份到档案馆的「素材」页；作品自己原来的 GrandTreeDB 仍然保留，用于即时渲染。

其他作品的配置会先作为档案保存，等作品代码支持后再生效。

## 数据保存在哪里

- 档案馆使用 IndexedDB，数据库名：`interactive-lab-archive`。
- 圣诞树自己的照片和音乐使用 `GrandTreeDB_v16`，文字设置使用 `localStorage`（`v16_text_config`）。
- 「日常节律」自己的任务和心情仍使用 `localStorage`，按日期分别保存。
- 数据属于「当前浏览器 + 当前访问地址」。换浏览器、换端口、清除站点数据，都可能看不到原来的档案。
- **重要**：定期在档案馆的「导出 / 恢复」里导出完整备份。

## 怎么增加一件新作品

1. 在同一个文件夹里做一个新的 HTML 文件，例如 `tide.html`。它可以有完全独立的配色和交互。
2. 在这个文件里引用共享脚本，并记录一次会话：

```html
<script src="lab-archive.js"></script>
<script>
  window.InteractiveLab.beginSession("tide");

  // 想记录某个动作时：
  window.InteractiveLab.logEvent("tide", "gesture", "点击了一次潮水");
</script>
```

3. 打开 `archive.html`，点「新建作品」，把入口文件填成 `tide.html`。
4. 打开 `index.html`，复制任意一个 `<article class="work-card">` 区块，改成新的标题、描述、封面和链接。

如果不想手动改代码，也可以直接让 Claude 帮你加。

## 设计约定

- 主站：淡紫 `#b9a8d4`、雾蓝 `#b5ccd9`、米白 `#f7f4ed`，编辑杂志式排版。
- 主站保持简约明亮；单个作品可以有自己的视觉风格。
- 圣诞树：黑色夜色 + 金色粒子、红色浆果，Three.js 三维场景。
- 山海之间：深蓝夜色 + 雾蓝月光。
- 档案馆：米白纸面 + 淡紫强调色，功能优先。
- 主站封面：圣诞树、星际漫游、日常节律使用 `assets/covers/` 里的照片；山海之间和林间漫步保留插画。

## 当前边界

- 版本快照目前保存的是**作品配置**，不会复制素材本身；素材以当前档案为准。
- 正式版圣诞树仍然以自己页面里的设置为准；档案馆是双向桥接，但恢复配置后需要在作品里点一下「读取档案馆设置」。
- 照片和音乐会在档案馆里再存一份，占用空间会比只存一份多。
- 圣诞树依赖网络加载 Three.js、MediaPipe 和手势模型；离线或网络受限时会退回纯视觉场景。摄像头被拒绝时，树仍然可以看，但手势功能不可用。
- 交互记录依赖各作品主动调用 `lab-archive.js`；新作品需要手动接入。
- 还没有云端同步。未来接入云端时，可以直接沿用现在的 JSON 备份结构。
- 档案馆只管理元数据，「新建作品」不会自动生成 HTML 文件。
