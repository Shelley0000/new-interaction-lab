# 星际漫游 · STAR WANDERER

一面全屏的情绪星云镜。你在前，星云在后。脸或手把情绪翻译成天气；要不要留下记录，由你决定。

## 运行

需要 Node.js 18+、Chrome / Edge 等支持 WebGL 与 `getUserMedia` 的浏览器。

```bash
cd star-wanderer
npm start
# 或 node server.js
```

打开 <http://127.0.0.1:5178>。摄像头权限只在本地使用；`127.0.0.1` 属于安全上下文，可以直接访问摄像头。

### 在 VS Code 里运行

这个项目没有构建步骤，也不需要安装依赖：

1. 用 VS Code 打开 `star-wanderer` 文件夹。
2. 终端菜单 → **运行任务** → **星际漫游：启动本地服务器**（或直接在终端执行 `node server.js`）。
3. `Ctrl/Cmd + 单击` 终端里的 <http://127.0.0.1:5178>。

不要双击 `index.html` 用 `file://` 打开：ES modules 和三个本地模型都需要通过 HTTP 读取。VS Code 的 Live Server 也能打开页面，但本项目的 `server.js` 额外设置了 COOP/COEP 响应头，兼容性更稳。

首次进入会从 `vendor/models` 加载三个本地模型（约 12 MB），随后全部推理在浏览器内完成。

## 操作

| 操作 | 作用 |
| --- | --- |
| 开始页「用表情 / 用手势」 | 选择输入方式 |
| 开始页「看见自己 / 只看星云」 | 选择人物是否入镜 |
| 开始页右上「情绪配色」 | 自定义五种情绪的颜色；不调整则沿用默认色 |
| 右上角 表情 / 手势 | 会话中切换模式 |
| `M` | 会话中切换模式（与右上角按钮等效） |
| `Esc` | 结束漫游，打开情绪气象卡 |
| `1`–`5` | 仅在摄像头不可用的演示模式中切换五种天气 |

表情模式会先做 3 秒中性校准。手势模式：👍 喜、👎 怒、✌️ 乐、伸出一只手指 哀、握拳 焦虑。手势模式右侧会一直挂着五枚手势提示；切回表情模式时收起。

背景是实时粒子星云：八条由一颗颗可分辨星粒组成的起伏粒子带、自由尘埃和亮星，会随情绪强度和动作幅度改变运动、亮度与颜色。同一个手势保持得越久，沉睡的星粒会逐渐亮起，颜色更浓、波浪的振幅也更大；手放下后海面会慢慢收平。颜色在 1.5 秒内渐变，不会硬切。

## 情绪故事

识别到情绪后，星云会很快聚成一场短小的粒子演出，2 秒内就能看到小人或第一簇烟花：

- **喜 / 乐**：星云快速旋转聚拢约 1.3 秒，在 2 秒内炸开第一簇烟花，随后持续放烟花约 5 秒，短暂回到星云后再次聚集、再次放烟花；只要这个手势还在，就循环下去。
- **哀 / 焦虑**：星云快速聚成一个小人，小人把一团暗色的坏情绪收拢、打包，然后用力扔向宇宙深处。整套动作约 6 秒，结束后恢复星云。
- **怒**：星云快速聚成一个小人，小人靠近你，轻快地拍三下，留下几圈暖光和细小的光点。整套动作约 5 秒，结束后恢复星云。

哀、焦虑和怒是单次演出；结束后星云恢复安静，等待下一次识别到新的手势。

开始页右上角的「情绪配色」可以给喜、怒、乐、哀、焦虑分别选一种主色；星云会自动把它展开成深色、中间调、高光与星色。没有调整的情绪继续使用默认色，选择只保存在本机浏览器里。

## 隐私

- 不录视频、不录声音、不上传任何画面；情绪配色只写进本机 `localStorage`。
- 表情模式只读取面部肌肉变化；手势模式只读取手部关键点。
- 情绪记录只保存：时长、输入模式、主要情绪、五种情绪占比、强度曲线、切换次数。
- 截图只会在情绪卡里明确选择「情绪记录 + 截图」并保存时生成，存进本机 IndexedDB 的档案馆。
- 演示模式只允许保存截图，不写入情绪记录，避免假数据污染档案馆。
- 页面隐藏 / 离开时立即关闭摄像头。

> 它是一次艺术化的读取，不是诊断。

## 目录

```
index.html            开场、准备、会话 HUD、情绪卡、档案馆
css/app.css           视觉系统与响应式布局
js/emotions.js        五种情绪的色板、文案、手势映射
js/vision.js          MediaPipe FaceLandmarker / GestureRecognizer / Selfie Segmenter
js/nebula.js          Canvas 2D 粒子波星云、人物抠像与柔边圆窗
js/story.js           情绪故事：聚星、烟花、小人打包坏情绪、拍拍你
js/archive.js         IndexedDB 档案馆
js/main.js            状态机、校准、模式切换、截图与记录
vendor/               MediaPipe tasks-vision bundle、wasm 与三个本地模型
server.js             零依赖静态服务器
diag.html             模型与抠像诊断页（开发用）
```

## 性能退路

默认用 Selfie Segmenter 把人物从背景中分离；如果渲染帧率持续低于 22fps（且「看见自己」），会自动退成柔边圆窗，不再跑人物分割。摄像头被拒绝或模型无法加载时，进入键盘 `1`–`5` 的演示模式，仍然能看到五种天气。

## 开发备注

- 无构建步骤，原生 ES modules；直接刷新即可。
- 测试素材与 Playwright 脚本在 `.test/`，不会在正式页面引用。
- 模型来自 MediaPipe，图标为 Tabler Icons（MIT）。
